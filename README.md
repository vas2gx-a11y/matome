# 自分専用まとめアンテナ

登録したまとめブログのRSSを20分ごとに自動で集め、広告なしの1ページにまとめて表示します。
サーバー代は0円で、GitHubの無料枠だけで動きます。

## できること
- 全ブログの記事を新しい順に1つにまとめて表示（サムネイル付き）
- 下のタブで「最新」「未読」「★ ブックマーク」を切り替え
- 未読は青い点と太字、既読はグレー。未読タブに件数表示、「全部既読」ボタンあり
- 右端の★でブックマーク。一覧からは3日で消えますが、ブックマークした記事は残ります
- 同じネタの記事をまとめて「他でも: ○○」と表示
- キーワードで絞り込み
- NGワード（`ng_words.txt`）を含む記事とPR記事は非表示
- ダークモード対応

既読とブックマークは、そのブラウザの中に保存されます。Safariで開いたときとホーム画面から開いたときでは記録が別になるので、どちらか一方で使ってください。

## セットアップ（PCで約10分、最初の1回だけ）
1. GitHubアカウントを作る（https://github.com 、無料）
2. 右上の「＋」→「New repository」。名前は `matome` などにして **Public** を選び「Create repository」
3. 「uploading an existing file」をクリックし、このフォルダの中身を**全部**ドラッグ&ドロップ →「Commit changes」
   - `.github` フォルダは隠しフォルダなので、表示されない場合はMacなら `Cmd+Shift+.` で表示
   - うまくいかない場合は「Add file → Create new file」でファイル名に `.github/workflows/update.yml` と入力し、中身を貼り付ける
4. 「Settings」→「Pages」→ Source を **Deploy from a branch**、Branch を **main / docs** にして「Save」
5. 「Actions」タブ → 「まとめ更新」→「Run workflow」で1回目を手動実行
6. 1〜2分後に `https://（ユーザー名）.github.io/matome/` を開くと完成

## iPhoneでアプリのように使う
Safariで上のURLを開く → 共有ボタン →「ホーム画面に追加」

## ブログの追加・削除
`feeds.txt` をGitHub上で開き、鉛筆マークから編集します。`表示名 | URL` の形で1行ずつ書きます。
保存すると自動で再取得されます。

## 取得できないブログがあるとき
ページ上部に赤字でエラーが出ます。そのブログのRSSのURL（livedoorブログなら `ブログURL/index.rdf`）を直接書くと解決することが多いです。

## 注意
- Publicのリポジトリなので、ページのURLを知っている人は見られます（検索エンジンには載らない設定にしてあります）。表示するのはタイトルとリンクだけで、記事本文はコピーしていません。
- GitHubは、60日間更新がないリポジトリの定期実行を止めることがあります。止まったら「Actions」から再開してください。
